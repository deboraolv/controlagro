Firebase / Firestore Todos os módulos leem e gravam diretamente no Firestore.
Persistência offline Todos os módulos usam Firestore como banco de dados.
☁️
Firebase como fonte única de dados

Cadastros, edições e exclusões de todos os módulos são persistidos no Firestore. Não há mais banco de dados paralelo em localStorage.

🛡️
Migração de segurança

Ao abrir esta versão, dados das versões anteriores que ainda estiverem no armazenamento local são comparados com o Firestore e enviados automaticamente sem duplicar registros equivalentes.

🧾
Histórico e exclusão segura

Edições geram eventos na coleção de auditoria. O botão Excluir usa exclusão lógica: o registro sai das telas, mas permanece armazenado no Firestore para recuperação.

O Firestore mantém cache offline persistente quando suportado. Alterações feitas offline ficam na fila e sincronizam automaticamente quando a conexão retorna.
